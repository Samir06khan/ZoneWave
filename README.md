# 🌍 Zone Wave

**Zone Wave** is a modern, responsive web tool built with React that helps users manage and visualize time zones across the globe.
It's designed to make global collaboration and scheduling easier by showing live clocks for multiple regions at a time in a clean and interactive UI.

---

## 🚀 Features

- ⏰ **Real-Time Clocks** – Displays current time across various global time zones.
- 🌐 **Global Coordination** – Designed to streamline international scheduling and team collaboration.
- 💡 **Animated UI** – Smooth, welcoming type animations powered by `react-type-animation`.
- 🎨 **Responsive Design** – Fully responsive layout using **Tailwind CSS**.
- 🖼️ **Custom Branding** – Includes a clean navbar with logo and a central hero section.
